# ai-json-parsers
Claude-generated python for parsing and generating indexed markdown for AI Studio exported json, saveai.net exported json, etc. inspired by https://github.com/tyashin/Claude-export-data-parser

parse_ai_studio_zip.py was generated by Gemini to parse the "Google AI Studio" directory downloaded as a zip file from Google Drive. The "Google AI Studio" directory is apparently created when sync is enabled.
